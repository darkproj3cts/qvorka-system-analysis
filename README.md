# Qvorka - маркетплейс фриланс-услуг

Портфолио-проект по системному анализу.
Предметная область - платформа для публикации и заказа фриланс-услуг (аналог Kwork).

## Что внутри

- `01-requirements/` - глоссарий, BRD, FRD, use cases, user stories
- `02-diagrams/` - BPMN, ERD, sequence и DFD диаграммы
- `03-api/` - OpenAPI 3.0 спецификация
- `04-database/` - DDL, DML, SQL-запросы и views
- `05-analytics/` - Jupyter Notebook с аналитическими запросами
- `06-wireframes/` - прототипы ключевых экранов

## Инструменты

draw.io · dbdiagram.io · Swagger Editor · PostgreSQL · DBeaver · Jupyter · Figma
